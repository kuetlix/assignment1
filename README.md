# Assignment 1 - React Product Dashboard

A small React application built with Vite that demonstrates React's core mental model: components, props, state, events, list rendering and composition with `children`.

## How to Run

```bash
npm install
npm run dev
```
Then open `http://localhost:5173/`.

## File Organization

```
/assignment1
├─ src/
│  ├─ components/
│  │  ├─ Card.jsx
│  │  ├─ Product.jsx
│  │  └─ ProductList.jsx
│  ├─ App.jsx
│  └─ main.jsx
├─ index.html
├─ package.json
└─ README.md
```
Config files in the root:

- `vite.config.js`: loads the React plugin for Vite.
- `.oxlintrc.json`: Oxlint linter configuration that comes with the Vite template.
- `.gitignore`: keeps `node_modules` out of the repo.
- `package-lock.json`: generated by `npm install`.

### Components

- **`App.jsx`**: Root component. Holds the `showProducts` (boolean) and `name` (string) state with `useState`. Renders the heading, toggle button, controlled input, greeting and conditionally renders `ProductList`.
- **`ProductList.jsx`**: Defines the static product array and renders one `Product` per item with `.map()`, using `product.id` as the `key` (not the array index).
- **`Product.jsx`**: Receives `title` and `price` as props, has no state, and wraps its content in `Card`.
- **`Card.jsx`**: Layout component that renders `children` inside a styled box (border, padding, margin). It does not know what it renders.
- **`main.jsx`**: Entry point that mounts `App` into `#root`.

## Challenges I Faced

1. **Deleting files I thought were unnecessary.** While cleaning the Vite template, I deleted `vite.config.js` and `.oxlintrc.json` because I thought they were boilerplate. I later learned that `vite.config.js` loads the React plugin the project needs to run properly, and `.oxlintrc.json` is the linter configuration that the `lint` script in `package.json` relies on. I restored both files from the Git history using `git checkout <commit>^ -- <file>`, which also taught me how to recover deleted files with Git.
2. **Deleting and reinstalling `node_modules`.** I removed and reinstalled `node_modules` while fixing the project setup. I learned that `node_modules` is generated by `npm install`, so it must not be committed and is listed in `.gitignore`. Vite also re-optimized dependencies because the lockfile changed, which is normal.
3. **Cleaning the template to match the required structure.** I removed the default Vite files (`App.css`, `index.css`, `assets/`) and had to make sure `main.jsx` no longer imported the deleted CSS file.
4. **Understanding the dev server.** At first I got `ERR_CONNECTION_REFUSED` in the browser. The reason was that the dev server was not running. `npm run dev` must stay running while testing in the browser.
